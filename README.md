# Hospital Management System

This is a PHP-based Hospital Management System. It includes modules for admin, employee, patient, pharmacy, laboratory, and more. The system is designed to streamline hospital operations, including patient management, billing, inventory, and reporting.

## Features
- Admin dashboard
- Employee management
- Patient records
- Laboratory and pharmacy modules
- Accounting and payroll
- Equipment inventory
- Discharge and admission management

## Technologies Used
- PHP
- MySQL
- HTML/CSS/JavaScript
- Bootstrap

## Getting Started
1. Clone the repository:
   ```
   git clone https://github.com/kenpetermaina/Hospital-Management-System.git
   ```
2. Import the `hmisphp.sql` file in your MySQL database.
3. Configure database connection settings in the PHP files as needed.
4. Run the project on a local or remote server with PHP support.
